# Contratos

Contratos do **Gerenciador de Áudio Visual**.

Contratos versionados entre backend, frontend, agente e integrações.

- `openapi`: especificação REST OpenAPI 3.1;
- `events`: envelopes e esquemas de eventos;
- `generated`: clientes e tipos gerados, quando aplicável.

O contrato atual inclui identidade, empresas, projetos, catálogo, máquinas,
operações e conexão OAuth com o Google Drive. Pastas, lotes e upload retomável
ainda serão acrescentados incrementalmente.
